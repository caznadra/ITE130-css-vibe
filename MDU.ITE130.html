ITE130 - Interaktiva användargränssnitt


Git, ett måste om du vill klara kursen

Git är ett verktyg som sparar en historik över ändringar i din kod. Du kan spara tydliga versioner av projektet och gå tillbaka om något blir fel. Med grenar kan du prova nya idéer utan att ändra huvudversionen. Git används på din dator, medan GitHub är en webbtjänst där du kan lagra och dela Git-projekt.
